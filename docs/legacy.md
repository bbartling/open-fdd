# Legacy

Earlier Open-FDD deployments (the 4.x central stack, Streamlit and Railway installs, MQTT ingest and similar) are no longer supported.
Only the Normal Framework app is. The 4.x design is frozen at release
[v4.0.11-central](https://github.com/bbartling/open-fdd/releases/tag/v4.0.11-central).
