# Open-FDD agent workspace — orientation

**Storage mandate (mandatory): TIMESCALE/POSTGRESQL ONLY. ONE CANONICAL TELEMETRY WRITE PATH. NO DUAL RECORD WRITING.** Parquet, Apache Arrow, Arrow IPC, Feather and DataFusion are prohibited in active product storage, caching, execution and dependencies; only `archive/` may contain them, labeled historical. Derived FDD / analytics results persist in PostgreSQL or bounded memory. NF portal REST, NF LAN gRPC (per-site `transport`) and CSV share one validated, idempotent Timescale telemetry writer — no parallel historian, raw-data mirror, or legacy fallback. Canonical text: [`DATA_CONTRACT.md` § Storage mandate](DATA_CONTRACT.md#storage-mandate-timescalepostgresql-only-mandatory). **Hosting mandate (mandatory): LOCAL SINGLE-HOST STACK ONLY.** Railway and any cloud web-app hosting (PaaS) are retired and prohibited, like DataFusion, Parquet and dual record writing: no Railway configs, CLI scripts, workflows, re-pin steps or credentials. Old Railway notes are `historical/non-executable`. Soft-OPEN ≠ FQ. Stay Rust OSS. Worktrees `/tmp/open-fdd-wt-*` only — never Desktop. **architecture_epoch:** `portal-timescale-v1` (Normal Framework API — portal HTTPS REST or LAN gRPC per site — + CSV, local single-host central + web, Timescale).

Plain Markdown on disk is the source of truth for **Cursor**, **Codex CLI**, and
similar agents. Product code lives in `services/`, `sql/fdd/`, `frontend/web`,
`mcp/`, and the `edge/` helper crate. The edge process and OT wire clients live in `archive/ot-edge/`. `os/` is a future concept. PyPI libraries live in `open_fdd/`. Orchestration lives in
**`openfdd_agent_spec/`**.

Those paths are sync targets of [`scripts/openfdd_install_agent_skills.sh`](../scripts/openfdd_install_agent_skills.sh) (`--sync`, optional `--user`). Edit the file in `skills/`, then sync.

### Equipment typing contract

Package `equipType` / `equipment_type` stamps are the classifier (rule 64). Opaque ids are valid when stamped (`AC_1` + `equipType: ahu` is an AHU). A missing or unrecognized stamp is unclassified for plots, RCx, overview cohorts, weather selection, motor groups, VAV health, and rule applicability. Do not infer kind from `equipment_id`. Never solve a site-specific naming problem by hard-coding a vendor, campus, building, or fixture equipment id into product code. Building and campus **identity** is always a caller parameter (`building_id` from package, request, JWT, or env). Equipment selection for plots, FDD, analytics, and type-first stress selectors uses the stamp, roles, and the registry — never a preferred fixture id, and never a substring, prefix, `LIKE`, `contains`, or `starts_with` on `equipment_id` (`RTU_01` must not select `RTU_010`). An exact id is allowed only after the type filter. Do not invent an MQTT delta payload. Parent-AHU id proposals are not cohort membership and are not a plot filter. Skill: [`data-modeling`](skills/data-modeling/SKILL.md) · [`openfdd-site-identity`](skills/openfdd-site-identity/SKILL.md). Epic: [#1043](https://github.com/bbartling/open-fdd/issues/1043). Id text is not an authorized fallback ([#1045](https://github.com/bbartling/open-fdd/issues/1045), [#1046](https://github.com/bbartling/open-fdd/issues/1046), [#1047](https://github.com/bbartling/open-fdd/issues/1047)).

**ZONE control** = fan-coil (`fcu`, valve PID hunting) **or** standalone DDC zone monitor — both get Overview schedule/comfort + zone sensor fault equations (`equipType: zone_other` / `fcu` / `zone`). **Unit ventilator** = CV AHU (`unitVentilator` / `uv` / `cv_ahu`) — same as constant-volume AHU, **not** ZONE. Detail: [`docs/modeling/zone-terminals.md`](../docs/modeling/zone-terminals.md) · [`DATA_CONTRACT.md`](DATA_CONTRACT.md).
