**Parent:** [`patch_all_open_issues_master.plan.md`](patch_all_open_issues_master.plan.md)

## Goal

Scoped CSV users (e.g. `joel_demo` / `joels_space` with `BUILDING_50` only) can open Sites without `building_id`, see **only** allowlisted buildings, and never observe ACME MQTT/edges/historian.

## Exact code homes (from research)

- Gate: `deny_if_building_out_of_scope` in [`services/central/src/routes.rs`](../../services/central/src/routes.rs) (~L1027–1071)
- List handler: `csv_import_package_buildings` in `routes.rs` (~L3798–3825) — currently applies the gate even when SPA sends **no** `building_id`
- Filter bug: post-filter reads `b.get("building_id")` on **string** building ids from `list_package_buildings_handler` in [`edge/src/csv_ingest/package.rs`](../../edge/src/csv_ingest/package.rs) (~L1758–1790) → empty id → **keeps every building** (the #1090 leak)
- Allowlist: `TenantContext::allow_building` in [`services/central/src/tenant.rs`](../../services/central/src/tenant.rs)
- SPA caller (no query params): `listPackageBuildings()` in [`frontend/web/src/api/mappingApi.ts`](../../frontend/web/src/api/mappingApi.ts) → `SitesPanel.tsx`, `HomePage.tsx`, `OracleSidebar.tsx`, Mapping/Rules pages
- Extra hole same PR: `get_edge` (~L1966–1991) has **no** tenant check (copy `list_edges` / `authorized_edge_ids` pattern)

## Implementation notes (order inside one PR)

1. **#1090 first (security):** Filter string **and** object elements; **fail closed** on unparseable id (drop empty-id allow). Root cause: `buildings` is `Vec` of strings in `package.rs` but filter used `.get("building_id")` → always `""` → keep all.
2. **#1089:** Split list-scope helper (filter on `None`) from per-object `deny_if_building_out_of_scope` (unchanged 403). Prefer moving helpers into `tenant.rs` to shrink `routes.rs` conflict surface for later PRs.
3. **#1088:** Empty-tenant Overview → usable empty state, not raw JSON error text.
4. **Bonus:** Tenant check on `get_edge`.
5. SPA: drive Sites from `/api/tenants` `buildings_visible` when useful; auto-select single building.
6. Tests: permanent Rust test that string-array filter **drops** foreign building; vitest no `building_id required` in Sites chrome; run gates `31`, `27`, `22`.
7. VERSION patch bump — treat as security tip.
